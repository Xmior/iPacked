Language

            

              
              
              
            

            
Turkish is a first draft translated from English. Fix any text with Edit texts: your changes are saved to lang/tr.json and override the built-in translation. You can also add a new language there.

          

          

            
App Store account ipatool · library and downloads

            

            

              
              
              
              
            

            
On first sign-in ipatool pulls Apple's authentication files out of a macOS restore image. This one-time step can take 10–30 min depending on your connection; don't close the app. Later sign-ins take seconds.

          

          

            
Signing account Impactor · install by re-signing

            

            

              
              
              
            

            
Note: encrypted (FairPlay) App Store IPAs don't launch once re-signed; install them with Install directly on a device signed in with the buying account.

          

          

            
Archive folder

            
          

          

            
File names IPA / PKG saved to the archive

            
            
Example: 

            

              
<Appname>App name as shown on the device (CFBundleDisplayName)Minecraft

              
<name>App Store name (for dumps: the original IPA's store name)Minecraft: Dream it! Build it!

              
<version>Version (CFBundleShortVersionString)0.3.3

              
<BuildNo>Build number (CFBundleVersion)0.3.3.1

              
<BundleID>Bundle identifiercom.mojang.minecraftpe

              
<ExternalVersionID>App Store version ID. Dumps take it from the original IPA; if unknown it stays empty and its brackets are removed.9470435

            

            
Dumps (decrypted IPAs) get .decrypted added automatically. If a file with the same name exists, (2) is appended.
